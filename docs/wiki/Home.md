# LJPc calendar module for FreeScout

Calendars inside FreeScout, right next to your conversations: calendars stored in FreeScout itself, Google Calendar, Microsoft 365, any CalDAV server and the ICS feed of any other app.

> This wiki describes version 3.0 of the calendar module and later.

## Set up a calendar

Every calendar is set up under Manage > Settings > Calendar. A FreeScout calendar and an ICS feed need nothing more than a name. Calendars of an account connect through the Connections tab first:

- [Google Calendar](Google-Calendar): create the OAuth app once, then connect Google accounts and Google Workspace accounts.
- [Microsoft 365](Microsoft-365): register the app once, then connect work accounts and the shared mailboxes they can open.
- [CalDAV](CalDAV): connect Nextcloud, iCloud, Fastmail, Baïkal, Zoho, cPanel and every other CalDAV server.

Each calendar then gets its own color, time zone, default reminder, custom fields and the people who may use it.

## Work with it

- [Invites](Invites): add the invites customers send with one click, answer them, and invite customers to events of your own.
